## Current gate, not the historical bundled-web gate

- `.github/workflows/ci.yml` delegates to `scripts/ci.sh`: frozen install → format/lint/typecheck → paired build → offline transport → all root tests (three Bun workers, paid tests disabled) → standalone paired smoke. macOS runs source transport plus deterministic Live tests, not the full Linux suite.
- `package.json`'s `test` builds first; raw `bun test ./tests` does not. `scripts/smoke.sh --reuse-build` requires both compiled pair members. Missing dist from an unbuilt checkout is setup failure, not product regression.
- `scripts/ci-selective.ts` now permits only modifications to existing audited reference docs; other/unknown changes require full CI. `scripts/find-ci-baseline.ts` carries changes since successful trusted ancestor CI; PR planning checks the actual merge tree. Always-run CI policy rejects failures and unexpected skips.
- `dependency-updates.yml` validates changed candidates with the Linux gate and notice generation. `release.yml` separately requires final external official-T3 acceptance and actual Mac binary/updater checks before publication. `live.yml` checks native helper/compiled loopback transport without devices.
