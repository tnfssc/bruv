## Review

Verdict: revise. The main fault was repeated structure, not a shortage of adjectives to replace.
Slop tells: brand/category eyebrow repeated the fixed header; numbered category + feature heading + explanation + demo caption + stage caption explained each panel several times. Parallel stacks made the actual example harder to find.
Specificity missing: none needed inventing. Existing worktree, job completion, and wisdom-file mechanisms carry the claims.
Inflated claim: no new performance or model-quality claims. Mock cost/context/footer values belong to the scripted UI, not measurements.
Flow break: repeated labels interrupted the move from benefit to demonstration.
Concrete rewrite: delete the hero eyebrow, all three numbered category labels, per-panel “Animated demo · scripted”, stage captions and permanent Play/Pause/Replay rows. Use one “Scripted demos, not recorded model runs.” note directly before the demo group. Keep one heading and a short explanation per feature.

## Before → after

- “Delegate an independent change without mixing it into your checkout. Ask Bruv for a worktree, then review the diff before bringing it back.” → “Ask Bruv to put an independent change in a Git worktree. Review its diff before merging into your branch.” The action and boundary replace an abstract introductory sentence.
- “Run a long test suite in the background and keep the conversation going. Bruv brings the result back when the job finishes.” → “Keep talking to Bruv while a test suite runs. The result returns to the conversation when the job finishes.” Names the concurrency relation without repeating the category label.
- Two wisdom sentences → “Save decisions and unfinished work in your project's wisdom files so the next session can read them before editing.” The connective names why the files matter.
- Demo: “Tests are running. We can keep talking.” → “Import tests are running.” The next user turn demonstrates continued conversation; the extra claim is unnecessary.
- Demo: “CSV import now streams rows. Regression tests pass. The fix is on its own branch; review the diff before merging.” → “The fix streams CSV rows and passes the import tests. Review its branch before merging.” Removes the three-beat outcome recital while retaining review ownership.
- Demo: “Quoted newlines now pass. Kept streaming; updated wisdom/csv.md with the test and next step: cache invalidation.” → “Added the quoted-newline test and saved cache invalidation as the next step in wisdom/csv.md.” Keeps the concrete file and next action.

Verdict: keep the hero “Keep coding / while your agents work.” Its next sentence supplies the worktree mechanism, so this is earned compression, not a slogan substituted for an explanation. Keep installation/provider/platform requirements and Install/Source destinations. Keep source-shaped tool counts, task labels, editor prompt, and footer vocabulary inside demos: these are actual UI, not marketing headings.

Rewrite check: passes self-detectors. No invented facts, prestige adjectives, rule-of-three filler, decorative closure, X-not-Y cadence or em-dash antithesis. The shared scripted note is an evidence-scope boundary, not decorative contrast. Check applied to hero, headings, labels, explanatory copy, CTAs, fallback/switch text and demo dialogue; stage metadata remains internal to the timeline, not visible commentary.
Remembered line: “Review its diff before merging into your branch.”

Additional visible copy cuts: “scroll to explore” → “scroll”; the alternate-view sentence explaining that it contains the same website content → “Terminal view”. HTML playback tooltips name the demo (“Pause delegate demo”), rather than mechanically repeating a full marketing heading inside the control label.
