# Production repository handoff module

Added `src/remote/repository.ts` with exported capture, remote result, and guarded return APIs and `tests/remote-repository.test.ts`. The caller must wire these through the existing SSH task owner/client (hooks in `src/remote/repository.md`), persist manifest/patch/receipts per task and ask before any untracked transfer. The default includes all tracked staged + unstaged state, no untracked bytes. Safe return is worktree-only and checks HEAD/index/tracked state; conflicts and new files remain review artifacts. Remote untracked bytes are not returned. Bundles include reachable history. We did not run real SSH or Docker; Bun disposable Git tests pass. No broader values change: honesty about evidence and safe single-owner return remain the governing principles.
