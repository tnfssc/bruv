# Durable actual-agent task lab (2026-09-26)

[Code and instructions](../../experiments/remote-task-poc/README.md). Extends the [actual RPC fake-model probe](../../experiments/remote-agent-probe/README.md) rather than timer simulations: Linux owns die RPC, model calls, accepted launch, append-only events and outcome. Short-lived host processes model a Mac interactive coordinator and a disk transcript replica, not actual Mac testing. Remote profile is independent of local Live; no remote provisioning or secret transfer.

Observed with packaged die 0.15.3 SHA256 2cc2c23454d110ffcdb9701420aa3e07af2ac629443c966ac92c99bbc458afea and host Bun 1.4.2, Docker Linux: first verified run PASS, detached at 313ms, finished at 3636ms, 18 events, 21858 JSON event bytes fetched in post-detach sync. Four seconds no client requests; synthetic model supplied three turns and actual die tools returned two complete results, both available offline after container stop. This is deterministic fake-provider evidence, **zero paid-provider calls**, not latency characterization. TypeScript strict check passed with repository deps linked locally during test. Second run: detached at 295ms, finish at 3594ms, 18 events, 21858 event JSON bytes. It also checked per-run bearer auth, bad version/profile, cursor mismatch and conflicting stable ID.

Critical boundaries: fsynced append log and client replica make accepted records/outcomes readable offline, not crash-atomic transaction or exactly-once side effects. Restart against a disposable Docker volume increments epoch; completed outcome is retained, unfinished task becomes unknown rather than blind replay. Client rejects cross-epoch sync and requires explicit reconciliation. Durable question/reply workflow and Mac fixture-read capability remain absent: do not infer parent availability or silently approve. No production edits. Values unchanged: the single owner with honest stale replica already fits existing direction; prioritize proving decision waits before product implementation.

Final Docker-volume/restart run: detached at 320ms, finished at 3662ms; 18 events / 21858 JSON bytes; restart retained identity/completed outcome, advanced epoch, and stale client rejected cross-epoch sync. Docker picked a new random host port on restart; the runner rediscovers it. These are observed lab timings, not benchmarks.

Correction: offline CLI prints the full saved bounded event transcript, including assistant/tool output; verifier checks CLI output. Owner probes staged /opt/die version and validates token. Event caps reserve a persisted capped outcome and bound the JSON envelope and RPC line buffer. Reported bytes distinguish full event JSON, replica file, and post-detach catchup. HTTP requests time out; stale replicas without meta require explicit reconciliation. Question/reply, Mac capability, and interruption of a running task across restart remain untested/unimplemented.
