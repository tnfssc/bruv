The final-source parent validation used a TMPDIR inside its Git checkout under ".cache/". That invalidated four upstream non-repository fixtures (Git found the enclosing checkout) and the embedded-helper extraction assertion (the *temporary directory name* itself contained "/cache/"). A diagnostic Git-ceiling rerun passed the four upstream fixtures. Do not change product behavior or weaken those assertions to compensate for this environment.

For root validation, create a scoped disk-backed TMPDIR outside any Git checkout, e.g. beneath "/home/tnfssc/.local/state/die/test-tmp"; /tmp may be full. Set SHELL=/bin/sh so subprocess shell tests do not inherit an interactive fish/mise shell. Include Bun and system executables in PATH, because tests spawn Bun by Bun.which("bun"). Run `bun test ./tests` against an explicitly identified built dist/die (the root test command does not build); capture the source/build provenance separately.

This establishes that the initial failure was not reproduced in the corrected environment; it does *not* prove the temp path caused that compaction failure. Do not alter the compaction implementation or fixture solely on the initial failed assertion.
