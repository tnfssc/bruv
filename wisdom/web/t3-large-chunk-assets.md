# T3 pinned web: large syntax assets (2026-09-27)

> Integrated into `integrations/t3/upstream/die.patch`. Incremental patch names below are historical review artifacts, not current build inputs. See [final installer handoff](../packaging/install-local-warning-fixes-2026-09-27.md) for current evidence.

Source-of-truth baseline: the **latest** integrations/t3/upstream/chunks.patch (43,274 bytes when copied) and chunks-dependencies.patch from the sibling worker, not this parent's previous chunks.patch. Copied both into this worktree without modifying the sibling. Disposable build source (not committed): .cache/t3-web-large-data. Incremental patch **over that exact chunks.patch**: integrations/t3/upstream/chunks-large-data.patch. Apply after die.patch, dependencies.patch, chunks-dependencies.patch and chunks.patch according to the existing upstream bootstrap ordering; no package or lock changes needed. No release/push/tag.

Why: pinned Shiki 4.2.0 compiles two huge language JSON payloads as JS string literals; Pierre's worker and the shared highlighter import shiki/wasm, whose wasm-inlined module base64-decodes Oniguruma from JS. Vite compiles Pierre's worker independently, so a plugin on only the main build is insufficient. The incremental patch adds a build-only plugin to both pipelines; it emits the pinned binary as a hashed .wasm asset and substitutes a streaming instantiator, and emits cpp and emacs-lisp JSON as hashed data assets loaded with top-level await in the existing lazy grammar modules. ES worker format allows async imports. Dev graph is unchanged; production retains lazy grammar loading and the existing Shiki/Pierre API. Native data assets are real WASM/JSON, not JS renamed to hide warnings; no warning suppression or raised limits.

Measured after vp build: worker 833,555 -> 211,201 B; cpp grammar JS 626,166 -> 224,391 B + 59 B loader + 381,729 B JSON; emacs-lisp grammar JS 779,921 -> 176 B loader + 778,700 B JSON; inlined wasm JS 622,367 B -> 310 B loader + 466,610 B native onig.wasm. Other emitted assets include main 197,425 B, _chat 306,903 B, 12,042 B unrelated wasm language grammar JS. **Zero JavaScript files >500 kB**, no Vite large-chunk warning. CSS 513,809 B, HEIC 1,422,377 B wasm, ghostty-vt 630,932 B wasm, font 1,177,576 B remain non-JS assets; this work does not hide or alter them.
