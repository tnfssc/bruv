BEFORE YOU START / QUESTIONS

What is Bruv?

Bruv is a terminal coding agent built on Pi. The CLI includes background jobs, sub-agents, project wisdom and optional Herdr integration.

How do worktrees help?

A Git worktree gives independent code changes their own checkout. Keep focused work separate, then review and bring the pieces together. Read the workspace guide ↗

Can I use a web frontend with Bruv?

Bruv has a native connector for a separately installed, unmodified T3 Code frontend. T3 is not bundled with Bruv. bruv web shows setup guidance; compatibility is version-specific. See the external T3 setup and known limitations ↗.
