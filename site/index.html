A FEW THINGS TO KNOW

Before you
open a terminal.

What is Bruv?

Bruv is a terminal coding agent built on Pi. The CLI includes background jobs, sub-agents, project wisdom and optional Herdr integration. You configure credentials and models at runtime.

Is this running Bruv in my browser?

No. This page is a static site. Its demo switches between prewritten scenes; it does not run a shell, access your files or connect to an AI provider. The terminal styling is inspired by native terminal apps, including Ghostty. This page does not embed Ghostty or ghostty-web.

What about a web interface?

Bruv has a native connector for a separately installed, unmodified T3 Code frontend. T3 is not bundled with Bruv, and bruv web shows setup guidance rather than starting a web app. Compatibility is version-specific; read the external T3 setup and known limitations.

Where do I start?

Follow the repository’s install guide for supported systems and the current paired-release status, or build from source. Bruv’s code is MIT-licensed. Model providers have their own access requirements and may charge for usage.
