# Standalone wire-accounting experiment

Run from repository root: `bun test experiments/remote-wire-bench` and `bun experiments/remote-wire-bench/bench.ts 42` (replace NUL delimiters with backticks). No services, model calls, or network. Seed defaults to 42. Scenarios: 1/1, 1/100, 10/1000, and 1000/1000 active/total tasks. Each task has 32 synthetic events 20 ms apart, including three tool outputs (two ~640 characters, one ~16 Ki characters), question and result. Synthetic Unicode word samples are not real agent traces.

Independent axes (UTF-8 serialized JSON payload bytes only):

- **Repeated history:** replay complete canonical transcript of each active task after every event vs one full canonical event per frame (including *all* tool outputs). This is an intentionally naive baseline, not a production claim.
- **Status:** poll full status list of *all* tasks 32 times vs initial all-task snapshot plus changed active-task entries each tick. Inactive tasks stay idle with seq=0; active tasks update each tick. No status coverage is dropped. Snapshot/deltas cost more when all tasks change.
- **Lazy output:** full canonical event deltas vs summary deltas, with output availability ID/byte count. `lazyFetchBytes` separately counts raw UTF-8 output content for all active tasks (not a wire encoding or packet total). Lazy summaries plus this content are still not identical on-wire representations: JSON fetch wrappers and requests are omitted.
- **Batching:** one event per JSON array vs grouped JSON arrays, same events on both sides. Batch limit is 16 KiB serialized JSON and 40 ms simulated wait. A single oversized event is marked and immediately emitted above the byte cap; no splitting. Full-output batch includes oversized tool events.
- **Compression:** gzip level 1 per lazy batch vs uncompressed identical lazy batch. Compression is not compared against full transcript to claim a single combined gain.

Payload bytes exclude headers, TLS/SSH, packets, retransmits, output-fetch request overhead, and status subscription framing. Frames are logical arrays, not packets. The timer is synthetic flush scheduling, not measured transport latency. CPU timings were removed: a single noisy process run cannot support CPU conclusions. No memory bound is measured; prior heapUsed was only a snapshot, not peak/RSS. No durability, retention, authorization, disconnect/reconnect or actual flow control. Gap recovery requests contiguous cursor catchup; duplicate events must match complete immutable payload, and missing blob hydration throws explicitly. Use real traces and link tests before choosing framing or compression.
