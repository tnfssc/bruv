# Standalone wire-accounting experiment

Run: bun test experiments/remote-wire-bench; bun experiments/remote-wire-bench/bench.ts 42

No dependencies, services, model calls or real network traffic. Seed defaults to 42. Each simulated agent has 32 events over 640 ms (20 ms/tick): token, progress, three tool outputs (two ~640 characters, one ~16 Ki characters), question and result. Synthetic word samples include Unicode. These are not recordings of real sessions. Script serializes and parses actual JSON buffers; gzip uses zlib level 1 per batch frame. Bytes are serialized UTF-8 payload bytes, NOT packet totals, transport headers, TLS, SSH, retransmits or HTTP framing.

Baseline: each open task's complete canonical history resent after every event; separately poll a status list of all agents once per tick. Deliberately naive, not a claim about production. Cursor: only open tasks (ceil(1% of agents), at least one) receive ordered compact events with stable task-scoped IDs and monotone sequence numbers. Tool output has explicit availability ID/byte length and is retained in canonical local blob map. Compare raw event-per-frame to batches (16 KiB serialized cap, 40 ms timer cap) and gzip batches. Output fetch is separate; bytes do not include fetching all tool outputs. Slow reader: last-eight-event and full-task catchup size. Gaps require request from last contiguous cursor; duplicates are safe. This test does not implement durability, retention, real offline replica, reconnect, flow control or authorization. Preserve canonical output on remote disk and expose an explicit unavailable/error state at system level.

Timing columns are summed process elapsed times around encoding/parsing loops, not network RTT or reliable per-event latency (sub-ms rounding, JIT/GC noise). Heap figure is one-shot process heapUsed with fixtures and arrays alive, not peak RSS or per-agent process cost. Frame count is not TCP packet count. First/max delay is synthetic emission-to-flush wait, independent of transport. Run real transcript traces and real link tests before selecting framing or compression.
