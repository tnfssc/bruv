# On-demand current-repo Git probe (disposable)

Run from this checkout: `python3 experiments/remote-repo-probe/run.py`. Requires Python 3 and Git; no die runtime, credentials, network, or real remote host. Creates and removes temporary Mac/Linux-labeled repos; never reads or edits this checkout's repository data. Asserts failures; prints a per-run byte count and identities. Commit hashes and bundle byte counts change with Git/version/time. An unrelated mise trust warning from the caller's shell may appear; this script does not invoke mise.

The mock coordinator names tracked paths, requires **all dirty tracked paths** to be named, rejects untracked selection, lists omitted untracked filenames (not contents), captures HEAD OID, a full aggregate HEAD-to-worktree tracked diff hash, and a Git index-entry fingerprint, and exports a `git bundle create ... HEAD` plus `git diff --binary HEAD` for the named paths. The mock Linux side clones into its own task branch, verifies HEAD, applies the selected diff, commits an input snapshot, and edits independently. Return is a patch relative to that snapshot. The coordinator checks exact original HEAD, aggregate tracked diff hash, and index-entry fingerprint plus `git apply --check` before applying. Each refusal test compares HEAD, index entries/blob OIDs, and fixture worktree file bytes before and after. The test covers untracked selection, unselected staged-only edits, selected and unselected later edits, staging-layout-only changes, patch-check failure, and advanced HEAD. Selected staged-only and mixed staged/unstaged edits both transfer. An untracked and an ignored secret are absent from the remote checkout; ignored files are not enumerated. Refused results stay as separate artifacts in the temporary directory until the demo exits; the demo never merges them. Fresh state demonstrates success without erasing the selected original dirty edit.

“Exact original tracked state” means HEAD plus the aggregate tracked HEAD-to-worktree diff, **not** the index staging layout, untracked/ignored files, or an atomic snapshot. This probe additionally guards the index entries with a fingerprint: staging the same worktree content changes only index entries, leaving the aggregate diff unchanged; this probe refuses that case. Git bundle includes reachable committed history: omission of untracked/ignored secrets does **not** filter secrets committed in history.

This is a **refusal-first sketch**, not secure transport or an atomic integration protocol. Filename enumeration itself may disclose sensitive names; production UI must decide whether to show them and should not auto-include them. Unknown ignored files/submodules, sparse checkouts, LFS, hooks, non-UTF8 names, rename/mode changes, task-added files, symlinks, concurrent edits between gate and apply, and arbitrary local/remote process mutation are not covered. The patch is not a complete returned commit/history. Do not route arbitrary bundle contents to a trusted executor without an explicit trust boundary. Results for an advanced HEAD or changed tracked worktree need deliberate review/rebase in a separate workspace; this probe refuses rather than silently overwriting.
