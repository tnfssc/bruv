# Remote review atlas

Open [index.html](index.html) in a browser (double-click or file://); no server, install, CDN or build required. Use buttons to simulate launch, disconnect, catch-up, questions and crash; choose an experiment in the results explorer for scoped evidence and source links. Animation can be paused; reduced-motion preference is respected.

This is a **simulation** of local experimental findings, not a remote client. It runs no commands, makes no network requests and changes no production code. Linked Markdown source files are local to this repository. The offline transcript in the interactive scene is fabricated for the *illustration* only; numeric results in the explorer are taken from the linked experiment notes, not generated by the scene.
