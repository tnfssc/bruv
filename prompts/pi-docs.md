# Pi's documentation

bruv runs inside Pi. Read this when the user asks about Pi itself: its SDK, extensions, themes, skills, prompt templates, TUI, settings or packages. The system prompt names Pi's docs and examples folders; the paths below are inside them.

- Extensions: docs/extensions.md, examples/extensions/
- Themes: docs/themes.md
- Skills: docs/skills.md
- Prompt templates: docs/prompt-templates.md
- TUI components: docs/tui.md
- Keybindings: docs/keybindings.md
- SDK integrations: docs/sdk.md
- Custom providers: docs/custom-provider.md
- Adding models: docs/models.md
- Pi packages: docs/packages.md
- Settings: docs/settings.md
- Environment variables: docs/environment-variables.md
- MCP servers: docs/mcp.md
- Codemode scripts and non-LLM models such as classifiers and image models: docs/codemode.md
- Sessions and their files: docs/sessions.md, docs/session-format.md
- Everything else: docs/index.md

Read the Pi docs you need completely, and follow their links to related docs (for example tui.md for TUI details) before building anything.
